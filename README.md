# C++ Data Structures & Algorithms

A collection of C++ programs implementing fundamental **Data Structures**, **Searching & Sorting Algorithms**, **Graph Algorithms**, **Greedy Algorithms**, and basic **Object-Oriented Programming (OOP)** concepts.

## 📂 Project Structure

### Searching Algorithms
- Linear Search
- Binary Search

### Sorting Algorithms
- Bubble Sort
- Selection Sort
- Merge Sort
- Quick Sort

### Data Structures
- Stack
- Queue
- Circular Queue
- Linked List
- Sparse Matrix
- Binary Search Tree

### Graph Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Dijkstra's Algorithm
- Bellman-Ford Algorithm
- Prim's Algorithm
- Kruskal's Algorithm

### Greedy Algorithms
- Fractional Knapsack

### Recursion & Backtracking
- 4 Queen Problem

### Object-Oriented Programming
- Constructor Overloading
- Addition of Complex Numbers
- Addition of Time
- Friend Functions

### Miscellaneous Programs
- Leap Year
- Graph Representation

---

## ▶️ Compile & Run

### Using g++

```bash
g++ filename.cpp -o output
./output
```

### Using clang++

```bash
clang++ filename.cpp -o output
./output
```

Example:

```bash
g++ bubble_sort.cpp -o bubble
./bubble
```
